# v0.2.0 启动、运行时与页面响应

2026-09-13 初稿，2026-09-15 补充页面实测；基于 `17d35b4` 的本轮实现，源码版本仍为 0.1.1。最大普通历史上限改为 **1000**，默认 **200**，合法旧设置不迁移，置顶另计。本轮未归档、发布或改动真实历史。

## 本轮实施

- 首次仓储加载使用同一次读取所得的内容指纹，去掉立即重读；普通读取不再构造无用的 previous snapshot。需要前后差异的 mutation/显式 refresh 仍保留两份快照。
- 按 ID 查找先 reconciliation、再借用遍历，只克隆命中条目；外部 CLI 删除、同长度修改、revision 与失败处理语义保留。
- 指纹改为固定 64 KiB 分块 SHA-256，避免申请与文件等大的临时数组；保留 SHA-256 内容检测，不退化为仅比较文件长度/mtime。Release 对 sha2 单独采用 `opt-level=3`，其它包仍为 z。
- owned 展示快照原位遮罩敏感字段，不再次克隆普通文本；原始仓储与显式 reveal/copy 不变。
- macOS changeCount 未变时不获取设置；需要读取时只获取三个保存类型开关。500ms 轮询、变化 settle delay、不可用 token 回退不变。Windows 事件监听、Linux broker 未改。
- fixture 与列表基准扩展到 1000，允许性能 trace 记录至 1100（包括兼容置顶）。fixture 时间按展示顺序递减，确保原生脚本的 text/files/image 行与实际排序一致。
- 普通设置保存不再触发全量历史快照；只有遮罩状态改变才刷新展示，历史裁剪和外部变更继续通过 revision 事件同步。遮罩连续变化时丢弃旧请求结果，并在单飞请求结束后补读最新状态。
- fixture 设置读取/保存跳过真实登录启动项，确保页面保存测试只修改临时配置。
- 发现旧 fixture 只隔离配置仍会启动真实剪贴板 watcher：显式临时 fixture 运行现在跳过 watcher，启动/退出/交互 launcher 保留相同隔离环境。普通启动无此行为变化。

新增 fixture 专用的页面自动化事件与允许列表参数，复用已有性能 IPC；正常模式不加载探针，不增加产品 IPC 命令、运行时依赖或产品版本。缓存仍为 Rust 32 MiB 总量/8 MiB 单项，窗口仍是 main eager 加六个 lazy auxiliary，prewarm 和 ready generation 未改。没有通过无限缓存、丢弃 delta、延迟即时保存或弱化隐私换取性能。

## Rust 合成基准

Apple M2 / macOS 26.6.2 arm64；Rust release；1000 条文本的每条 text/displayText 均重复 256 次 `Fixture text 世界 `。每项先预热一次，5 批、每批 20 次；表内中位数/p95 是 **5 个批次单次均值** 的统计，p95 因样本量为该批次均值最大值，不是 100 个单次操作的尾延迟。文件系统缓存已热。分配计数为当前线程累计申请字节（包括重分配请求），不等于存活内存、峰值内存或 RSS。首次快照每次使用新仓储，含文件读取/解析/指纹，不包含 WebView 或 IPC。

| 1000 条场景 | 中位数前→后 | 批均值 p95 前→后 | 每次累计申请 bytes 前→后 |
| --- | ---: | ---: | ---: |
| 首次快照 | 113.75 → 40.23 ms | 116.03 → 42.37 ms | 55,268,383 → 34,313,580 |
| 已加载快照 | 53.14 → 30.22 ms | 53.40 → 30.28 ms | 31,381,693 → 10,427,018 |
| 查找末条 | 53.41 → 29.49 ms | 55.18 → 29.55 ms | 31,381,693 → 10,379 |
| 查找不存在 ID | 53.27 → 29.55 ms | 53.53 → 29.59 ms | 31,381,693 → 128 |

首次快照下降约 64.6%，末条查找下降约 44.8%。这里只证明这些合成核心路径。仅删 clone 的中间候选虽然明显减少分配，但耗时几乎不变，说明剩余瓶颈是全文件指纹；没有把分配下降直接当作吞吐收益。读取依然 O(文件字节数)，异常长历史文件的成本仍在。

原始 10/50/500/1000 样本：[基线](v0.2.0-desktop-reads-baseline.json)、[仅分配候选](v0.2.0-desktop-reads-allocation-candidate.json)、[最终优化](v0.2.0-desktop-reads-optimized.json)。SHA-256 与其它修改一起对比，没有单独拆出其收益占比。

相同 fixture、相同 11 项操作顺序下，[旧刷新逻辑基线](v0.2.0-native-pages-baseline-1000.json) 20 次保存每次都读 **1 次** history snapshot，候选均为 **0 次**。保存响应 median 为 **45.19 → 43.55 ms**（约 3.6%），p95 **51.64 → 51.79 ms**，没有达到 15% 的时延改善目标；本轮保留它的依据是确定消除了多余全量传输/渲染，而不是宣称原生保存速度显著提高。候选带前后各 60 秒资源采样，基线无此采样，因此时序/系统噪声也不能忽略；后端原子保存、外部文件检查和裁剪行为保留。连续遮罩切换的 stale response 与卸载保护由独立 hook 异步回归覆盖。

## 资源采样与待验边界

资源原始值包含在页面样本的 `resources` 中。通过 `ps` 累计 CPU 时间差除以实际采样时长计算，RSS 使用 KiB；只归属唯一 mclip 主进程，不累加其它应用的 WebKit/GPU/网络共享进程。性能 trace 处于开启状态。

| 主进程状态 | 采样时长 | CPU（一个逻辑核为 100%） | 结束 RSS |
| --- | ---: | ---: | ---: |
| 初始隐藏窗口，预热中/后 | 60.04 s | 0.067% | 91.9 MiB |
| 连续 26 轮页面操作 | 32.54 s | 13.98% | 106.9 MiB |
| 最后 quick-action 可见，空闲 | 60.04 s | 0.067% | 106.2 MiB |

没有主进程资源的改动前同协议对照，不宣称常驻内存/CPU 下降。fixture 关闭真实 clipboard watcher，并跳过自启副作用；生产 watcher CPU、可归属 WebKit RSS、七窗口全部隐藏、长文本搜索/持续复制/大图压力等完整资源矩阵仍未完成。保留 task 4.2、5.7。

七窗口与所有页内操作的完整矩阵仍见 [change design](../openspec/changes/optimize-v0-2-0-performance-and-size/design.md)。当前主列表/单条详情/viewer 的原生数据来自上一轮；本轮补了 About、Preferences 六页/搜索/保存及 JSON quick-action。分组 preview-detail 的 DOM focus/mouse 试验未稳定触发原生详情路径，未验证的探针已移除、失败尝试未计入原生成功数据；该项需复用真实系统鼠标协议继续验证。主窗口真实键入到绘制、viewer 首次/恢复、三类转换边界、系统/浅/深主题、错误回滚及跨屏 pointer 不能仅凭本表关闭。

Windows source/native、Linux 构建/命名会话保持 4.3/4.4 和 5.8 未完成。本次没有 Windows 专属修改。未运行安装包/异常 panic 验收，DMG 未重打，3–5 MB 目标状态不变。

复现核心基准：

```sh
cargo test --locked --manifest-path src-tauri/Cargo.toml --release --lib synthetic_desktop_reads -- --ignored --nocapture
node scripts/performance/build-list-benchmark.mjs
MCLIP_PLAYWRIGHT_MODULE=/absolute/path/to/playwright/index.mjs MCLIP_BROWSER_EXECUTABLE=/absolute/path/to/chrome node scripts/performance/run-list-benchmark.mjs
```

原生测量前确认没有其它 mclip 实例；二进制必须来自本轮带 fixture watcher 隔离保护的 release app，避免旧二进制读取真实剪贴板：

```sh
pnpm run perf:startup -- --binary /absolute/path/mclip.app/Contents/MacOS/mclip --count 1000 --warmups 1 --runs 5 --output /tmp/startup.json
pnpm run perf:interactions -- --binary /absolute/path/mclip.app/Contents/MacOS/mclip --count 1000 --warmups 5 --runs 20 --output /tmp/interactions.json
```

页面协议（fixture 会禁用系统剪贴板 watcher 和真实自启副作用）：

```sh
node scripts/performance/benchmark-pages.mjs --binary /absolute/path/mclip.app/Contents/MacOS/mclip --count 1000 --warmups 5 --runs 20 --resource-seconds 60 --output /tmp/pages.json
```

`--actions` 可指定允许列表中的逗号分隔子集；设置保存探针要求先打开 Preferences 并切到外观页。资源采样只报告主进程，不应当作完整应用内存。
