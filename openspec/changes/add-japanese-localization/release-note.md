## Release note draft

mclip now supports Japanese across the desktop application and official website. Users can select Japanese explicitly or keep “Follow System”; `ja` system locales resolve to Japanese, while unsupported locales continue to fall back to English. The Japanese website is available at `/ja/`, including localized product information and release notes with complete multilingual discovery metadata.

Clipboard contents, file-list restore behavior, commands, URLs, and technical tokens remain unchanged by the display language. `mclip-cli` command names, help, installer diagnostics, and output remain English-first in this release.
