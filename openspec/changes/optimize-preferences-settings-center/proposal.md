## Why

当前偏好设置已经覆盖通用、历史、隐私和 Agent CLI，但固定宽度页签、分散的卡片结构和缺少搜索，使设置项继续增长后难以定位，也无法清楚表达隐私保护与文本快速操作的边界。现在敏感内容保护和文本快速操作都已具备稳定实现，适合把偏好设置升级为一个紧凑、可搜索、可扩展的桌面设置中心。

## What Changes

- 将顶部页签改为 ChatGPT / Zero 式双栏设置中心：左侧提供分组导航与本地搜索，右侧提供页面标题、说明和纵向设置组；继续使用 mclip 现有双主题语义色与紧凑桌面密度，不复制参考产品的品牌色或装饰。
- 将现有设置重组为“通用、外观、历史、隐私、文本操作、Agent CLI”六个页面，并在“mclip”和“工具”两个导航组下呈现；设置名称、说明、搜索关键字和状态反馈全部支持中英文。
- 建立可搜索的设置元数据索引；搜索结果可跳转到对应页面、滚动并聚焦具体控件，`Escape` 优先清空搜索，再执行原有关闭窗口行为。
- 将布尔设置统一为右侧系统式开关，将枚举、数值、状态和动作使用各自合适的控件；保留即时应用、即时保存，不增加 Save / Cancel 页脚，并提供不阻塞整页的行级保存或错误反馈。
- 保留具体的隐私控制，而不新增含义模糊的“启用隐私功能”总开关：继续提供敏感内容遮罩、来源应用排除、平台能力状态和旧历史重新分类，并明确遮罩不等于静态加密。
- 新增桌面文本操作偏好，允许分别显示或隐藏 JSON、Base64 和 URL 组件转换；默认全部启用，只影响桌面详情中的操作入口，不改变 CLI `transform` 能力、资源上限、显式替换确认或本地处理边界。
- 将偏好设置窗口扩大为适合双栏信息架构的固定桌面尺寸，并保留透明圆角裁剪、平台侧窗口控制顺序、仅标题栏可拖动和辅助窗口按需创建协议。
- 本次不引入按时间自动清理、可编辑全局快捷键或暂停监听等跨运行时策略；这些候选项分别涉及置顶保留语义、快捷键冲突回滚和托盘状态，应在独立 change 中设计。

## Capabilities

### New Capabilities

- `preferences-settings-center`: 定义双栏导航、设置搜索、页面分类、控件模式、即时保存反馈、键盘与无障碍行为。
- `text-action-preferences`: 定义 JSON、Base64 和 URL 组件桌面快速操作的分组开关、默认值、兼容性与 CLI 边界。

### Modified Capabilities

- `appearance-settings`: 将语言与行为留在通用页，把主题、菜单栏图标和主窗口显示项整理到独立外观页，并保持双主题可读性。
- `dialog-window-chrome`: 将 Preferences 调整为双栏设置中心所需的固定尺寸，同时保留现有自定义窗口控制和拖动边界。
- `history-display`: 将保存类型、历史上限和两类显示条数迁移到新的历史页面，同时保留原有取值范围和即时保存语义。

## Impact

- 前端：拆分 `PreferencesWindow` 的 shell、导航/搜索元数据、页面组件、设置行控件与行级反馈；更新 `uiStyles.ts`、语义主题样式、中英文文案及文本快速操作适用性过滤。
- 数据契约：在 Rust `AppSettings` 与 TypeScript `AppSettings` 中对称新增文本操作分组设置，旧设置文件缺省为全部启用，并由前后端共同归一化。
- Tauri：更新 `preferences` 辅助窗口描述符尺寸；不新增窗口、插件、网络请求或辅助运行时。
- 兼容性：现有设置键、历史数据、隐私分类、CLI 行为、quick-action 结果窗口和即时保存协议保持兼容；只增加可选设置字段并重组 Preferences 展示。
- 测试：增加导航、搜索跳转、键盘/ARIA、即时保存反馈、双语元数据、设置迁移、文本操作过滤和窗口描述符回归；保留 macOS 与 Windows 真机 UI smoke 边界。
