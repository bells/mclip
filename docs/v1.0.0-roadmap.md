# v1.0.0 开发范围

记录日期：2026-10-25。开发分支：`v1.0.0`。

这是当前版本范围和待定事项的入口，后续可以补充。分支名称不代表版本号已升级或版本已发布；源码版本暂时保留 `0.2.0`。

当前阶段仅推进图标升级。已有托盘 Bug 修复保留，新的 Bug 工作和自动更新暂缓。

## 1. 修复已知 Bug

- 已实现 macOS 托盘左键被原生菜单接管的修复：左键释放切换主窗口，右键释放显式显示菜单。
- 已给 Linux AppIndicator 托盘菜单增加“打开 mclip”入口，避免依赖不受支持的点击事件。
- 当前自动化证据：完整本地检查通过，Rust 265 项通过、3 项忽略，根目录 230 项测试通过；Windows x64 全目标交叉编译通过。
- macOS 修复包已在本机备份替换并重启；左键/右键原生点击验收待确认。
- Windows 真机点击验收、Linux 构建和桌面会话验收待完成。Linux 的主窗口入口与点击限制见 [Linux 支持说明](linux-support.md#tray-activation)。
- 后续发现的 Bug 继续按具体问题登记和修复，不预设额外功能。

## 2. 图标升级

- 已选定第二稿：圆润枫叶、流线小写 m 镂空、低饱和赭红色、透明底。
- 三种状态栏选项全部保留：`appIcon` 对应新彩色枫叶，`light` 对应单色枫叶，`m` 保留原记事本；无需迁移已有选择。
- 同步桌面应用、主窗口、About、Preferences 与官网当前静态品牌图标；保留 v0.x 视频和历史截图。
- 规范源、导出流程、自动化和原生验收状态见 [枫叶图标 change](../openspec/changes/refresh-maple-icon-identity/tasks.md)。
- [菜单栏 M 图标 change](../openspec/changes/refine-menu-bar-notebook-m-icon/proposal.md) 的源和衍生资源保持不变，不替代其未完成的原生验收。

## 3. 自动更新能力

- 保留为 v1.0.0 候选事项，当前暂缓，方案和实现尚未开始。
- 当前 About 的手动版本检查与打开 Release 页面，不等同于自动下载和安装桌面更新；CLI 安装更新也不代表桌面自动更新。
- 需明确更新检查时机、用户确认流程、平台支持范围、更新源、签名与验证、安装重启，以及失败恢复方式。
- 优先评估 Tauri 2 官方 updater 生态；具体方案在独立 OpenSpec change 中确定后实施。
